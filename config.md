### Keyboard Shortcuts

`shortcut_copy` specifies the keyboard shortcut for **Copy Deck Guide as Text**. It is disabled by default.

`shortcut_save` specifies the keyboard shortcut for **Save Deck Guide as Text…** The default is `Meta+Ctrl+Shift+G` (`⌃⇧⌘G`); set it to `""` to disable it.

On macOS, Qt interprets `Meta` as Control (`⌃`), `Ctrl` as Command (`⌘`), `Alt` as Option (`⌥`), and `Shift` as Shift (`⇧`).

No restart is required.
